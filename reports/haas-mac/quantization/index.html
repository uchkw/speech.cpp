Choosing and running a model

In the app: Settings → Recognition → Model → Save settings persists the fully qualified model value. Prepare loads it now, the next recording loads the new model before capture, and a file import with a speech region prepares the selected model too — no app restart is required. Device stays auto at 4 threads.

The four quantized formats default to CPU decode; F16 defaults to Metal on this accelerator, and F16 CPU still requires the explicit CLI flag.

Conditions and limitations

  • Peak MiB is the maximum process footprint across the entire cohort run, not the footprint of one duration stratum or input.
  • p99 rests on only 30 public and 48 private inputs — a tiny sample; treat it as indicative.
  • The private cohort has no gold reference: private CER is unavailable, agreement appears as exact and normalized counts against Q4_K, and free text from private sections is ignored.
  • Measured scope is the whole worker request with no keywords or VAD context — not decoder-only, and nothing here is a whole-app claim.
  • Unrecognized summary keys are ignored by this page.
