Conditions and limitations

Time from before sending the first PCM16 chunk through receipt of the terminal result. File reading, model loading and warmup are excluded. Each measured input is warmed once per fresh worker.

Median over rounds for each input, then linearly interpolated p50, p90 and p99 across the measured input medians. RTFx divides total audio duration by summed request time.

Literal CER: Total Unicode code-point Levenshtein edits divided by total reference code points, including punctuation, symbols and whitespace.

Repository CER: NFKC followed by removing Unicode punctuation, symbols, separators and whitespace; no case folding or alternate-spelling substitutions. Edits and reference lengths are summed before division.

  • The current corpus is FLEURS Japanese test, with inputs from 6.36 to 28.2 seconds.
  • The p99 of a small duration-stratified sample is not a precise estimate of production tail latency.
  • The repository CER is not the published metric accepting alternative spellings of words.
  • Fresh-process load and first-request times do not reset filesystem or system Metal caches.
  • The 9-clip screen gives a limited estimate of tail latency. The full corpus and additional timing rounds were not run.
  • The changed KDA/TDT stage has no official end-to-end decoder tensor reference in this evaluation. Raw IDs, frames and durations were checked through the dedicated C++ differential path. The worker exposes public text, tokens and segment times. Callback-sequence equality on the 11 projections alone does not prove that every optional cutoff fired.
  • The trial did not exercise Windows Vulkan or non-Haas models with matching stage dumps. Direct shared-Graph cases covered the exercised CPU and Metal paths.
  • Process peak footprint includes the entire worker. The trial did not measure allocator-call counts, a full memory breakdown or isolated VRAM. Fresh workers retain the operating system's file and Metal caches.
  • The original and final candidate products matched on 74 compiler flag files and 74 link commands with paths normalized. The fixed anchor used implicit architecture and SDK defaults. Their effective equivalence to the explicit arm64 and SDK settings of the matched products was unverified. The primary switch comparison used one executable.
