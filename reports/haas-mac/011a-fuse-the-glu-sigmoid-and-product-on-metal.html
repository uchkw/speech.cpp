Conditions and limitations

Time from before sending the first PCM16 chunk through receipt of the terminal result. File reading, model loading and warmup are excluded. Each measured input is warmed once per fresh worker.

Median over rounds for each input, then linearly interpolated p50, p90 and p99 across the measured input medians. RTFx divides total audio duration by summed request time.

Literal CER: Total Unicode code-point Levenshtein edits divided by total reference code points, including punctuation, symbols and whitespace.

Repository CER: NFKC followed by removing Unicode punctuation, symbols, separators and whitespace; no case folding or alternate-spelling substitutions. Edits and reference lengths are summed before division.

  • The current corpus is FLEURS Japanese test, with inputs from 6.36 to 28.2 seconds.
  • The p99 of a small duration-stratified sample is not a precise estimate of production tail latency.
  • The repository CER is not the published metric accepting alternative spellings of words.
  • Fresh-process load and first-request times do not reset filesystem or system Metal caches.
  • This screen rejects only the GLU sigmoid/product prototype. Pointwise projection plus GLU remains unfinished. The production default, fixed anchor and cumulative campaign baseline are unchanged.
  • Nine balanced recordings per type and three alternating rounds can reject a variant but cannot establish a production tail improvement. The observed round range is descriptive variation, not a confidence interval.
  • Quality scores cover nine recordings per type only. Full 650-input quality and sub-6-second follow-up are not run after this rejection.
  • The same-binary OFF/ON comparison is primary. Fresh original/candidate builds explicitly set arm64 and the Xcode macOS SDK, and all 74 speech plus 28 ggml flags.make files match after source/build path normalization. The fixed anchor uses implicit architecture/SDK settings; equivalent effective defaults are unverified. Exact SDK paths remain in frozen build evidence.
  • Direct original/OFF/ON checks each cover 76 cases and two emulated poison guards. The 38 eligible cases fuse only with candidate ON; 38 controls include 12 mapped-buffer cases. The extra mapped-buffer controls are not CPU-reference cases.
  • Final mapped-buffer controls correctly reject fusion, but the intermediate pre-guard kernel is not run to reproduce the missing-guard failure.
  • Normal and retained encoder/joint projection helpers cover three weight types and seven lengths. They verify 24 fusions per normal ON graph and zero per retained graph. Their counters preserve the normal two-command-buffer policy; helper timings are excluded.
  • The executed official checks are frontend F32 CPU and encoder F32 CPU/Metal plus F16 Metal. The 99 case executions are separate from 126 normal/retained differential graph executions. Official checks retain intermediates and do not prove ordinary fusion counts.
  • Official joint.enc tensors exist but this trial does not run a separate official joint.enc check. Normal joint projection is differential only. Complete KDA/prediction and TDT reference checks and Windows Vulkan execution are unrun.
  • The initial GRAPH_DEBUG capture records no node trace because the default sink filters Debug logs. Its failure is retained. A separate log-only launcher captures the corrected diagnostic; neither diagnostic binary nor its timing contributes to the worker screen.
  • The public worker comparison checks text, public token text/times and segments, not private TDT IDs, frame indices or duration decisions.
  • Peak memory is gross process footprint, not separately measured GPU VRAM. Load and first-request results use fresh workers but do not reset filesystem or system Metal caches.
