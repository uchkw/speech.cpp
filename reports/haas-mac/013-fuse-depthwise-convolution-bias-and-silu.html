013 · Fuse depthwise convolution, bias and SiLU

rejected

Reject the current depthwise convolution + bias + SiLU prototype for the tested normal allocation path. Direct numerical checks pass, but no depthwise fusion activates in the ordinary encoder graphs. Reviewed Q4 storage ranges satisfy a required alias rejection condition. Primary latency, full corpus, short-audio and public ASR quality are not measured; this is not a measured 0% speed result.

Conditions and limitations

No primary request latency is measured. Diagnostic process wall times and check execution times are not request-latency evidence.

No latency quantiles, paired reductions, cumulative gain or CER estimates are computed. The index deliberately leaves the gain field empty.

Literal CER: Total Unicode code-point Levenshtein edits divided by total reference code points, including punctuation, symbols and whitespace.

Repository CER: NFKC followed by removing Unicode punctuation, symbols, separators and whitespace; no case folding or alternate-spelling substitutions. Edits and reference lengths are summed before division.

  • This is an applicability-only rejection. No primary screen, fixed-anchor timing, full 30-input latency/650-input quality, short-prefix screen, CER, public ASR text/token/time/segment comparison, load-time gain or memory gain is measured.
  • Direct synthetic arithmetic and ordinary-graph byte equality are not ASR corpus recognition-quality evidence. The campaign CER definitions below are unused scoring definitions, not results for this variant.
  • Seven unique subsampled lengths are executed nine times per process, including repeats at 33 and 1. Three model types and three original/OFF/ON configurations give 81 ordinary graph executions, not 81 unique lengths or utterances.
  • The normal allocator keeps only the final encoder-to-joint projection as graph output. Separate GRAPH_DEBUG=1 logs cover another 81 graph executions, and one Q4 ON GRAPH_DEBUG=3 run covers nine more; all debug outputs match normal outputs.
  • The initial diagnostic aggregation searched for five raw operations. The backend removes empty PERMUTE/RESHAPE nodes, so the corrected nonempty fusion has three operations. Both analyses and original raw logs are preserved; zero depthwise fusions remains the result.
  • The reviewed Q4 ranges contain 216 Conformer patterns: 120 output/input overlaps and 96 output/packed-kernel overlaps, union 216, with no bias overlap. They are sufficient local FULL alias-rejection conditions. The first rejecting branch is not instrumented, so its order is not established.
  • Ordinary unfused execution may reuse input or packed-kernel storage after convolution consumes it. No safety guard, allocator, retained intermediate or runtime is changed to force fusion in this evaluation.
  • Official coverage uses 11 unique dump inputs across nine stage/configuration invocations: 99 executions. Frontend and encoder are run; available joint.enc dumps are not independently executed here, and complete official KDA/TDT reference remains unavailable.
  • Official SNR values are displayed to one decimal place. Existing executables decide pass/fail with unrounded values and unchanged strict thresholds.
  • Windows/Vulkan device execution is unavailable. No numerical or performance equivalence is claimed there.
  • The direct set has 61 cases, including 11 mapped-buffer controls and one padded-input case outside the 49-case CPU-reference set. Two poison guards do not dispatch the GPU. Related regressions have 76 unsupported cases per configuration, excluded from passes.
  • Original/candidate builds use native Release Metal, explicit arm64 and the same Xcode SDK. Their 74 speech and 28 ggml flags.make files match after source/build path normalization. No full link-command equivalence claim is added.
  • The fixed anchor is identified and its files verified but not timed. Its implicit architecture/SDK settings differ from the explicit matched builds; no performance equivalence or cumulative campaign gain is inferred.
  • Normal helper checks use four CPU threads; direct/official check thread policies are recorded in their commands and are not a tuned worker request comparison. The runtime automatic default remains 16 performance cores on this host.
  • Frozen runner source is retained for the planned screen but was not executed. Proposed 013 Python execution tools and coding-session development artifacts remain outside the measured evidence and are not adopted.
  • Model and official-array hashes come from pre-execution verification. The independent report audit rehashes frozen raw/build artifacts, not model or reference-array contents.
  • This result concerns the current prototype and observed allocation path. The default remains OFF; no production variant, baseline or cumulative gain is adopted.
