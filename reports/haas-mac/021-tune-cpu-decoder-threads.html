Haas on Apple Silicon

021 · Tune CPU decoder threads

conditional

On the M2 Ultra, resolving omitted threads to four instead of sixteen shortened median paired requests by 6.27% on Q4_K, 7.49% on Q8_0 and 6.63% on F16. The current application already requests four threads. Changing the public automatic-thread contract still requires a compatibility decision.

The earlier thread comparison and this measured configuration change receive no additional credit for an application that already explicitly requests four threads.

        Conditions and limitations

        The worker timer starts before preparing and sending the first PCM chunk and ends after receiving the terminal response. Workers loaded and warmed all nine inputs before the measured requests.

        For each recording, take the median of three rounds before computing p50, p90 and p99. Paired reduction is one minus the median of candidate/original per-recording ratios. RTFx divides total audio duration by the sum of these per-recording median times.

        Literal CER: Total Unicode code-point Levenshtein edits divided by total reference code points, including punctuation, symbols and whitespace.

        Repository CER: NFKC followed by removing Unicode punctuation, symbols, separators and whitespace; no case folding or alternate-spelling substitutions. Edits and reference lengths are summed before division.

        • The same nine public Japanese FLEURS inputs were used for all three weight types and every thread setting. Tail percentiles are interpolated from nine input medians. The separate 650-input quality run covered Q4_K only.
        • No 30-input latency run, two- or four-second prefix test, other Mac, Windows or Vulkan performance test was run. Wall-clock performance of other model families and the hidden TDT IDs, frames, durations and logits were outside this trial.
        • The process peak is the maximum macOS footprint over the three timed workers and the separate timestamp-enabled quality worker for that configuration. Load to ready and first warmup request use the medians of the three timed workers. Filesystem and system Metal caches were retained.
        • The original 114c514 was measured again on the same public inputs. Its normalized compile flags and link recipes matched the candidate on 74 files each. An earlier campaign anchor was not timed in this sweep.
