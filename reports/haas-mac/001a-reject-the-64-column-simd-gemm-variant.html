Haas on Apple Silicon

001a · Reject the 64-column SIMD GEMM variant

rejected

The 64-column variant increased paired warm request latency by 8.6% for Q8_0 and 13.7% for F16 on nine inputs over three rounds. Q4_K was an unchanged-path control. No implementation is adopted; other GEMM variants remain open.

Conditions and limitations

Before encoding/sending first PCM16 chunk through terminal worker end event; file reading, model load and warmup excluded.

Linear-interpolated percentiles across nine per-input median latencies; exploratory tail estimates, not production p99 guarantees.

Literal CER: Total Unicode code-point Levenshtein edits divided by total reference code points, including punctuation, symbols and whitespace.

Repository CER: NFKC followed by removing Unicode punctuation, symbols, separators and whitespace; no case folding or alternate-spelling substitutions. Edits and reference lengths are summed before division.

  • No measurements below 6.36 seconds.
  • No full-corpus or official-reference accuracy conclusion.
  • No Windows Vulkan or other-Mac validation.
  • No independent original-shader versus experimental-32 bitwise comparison.
  • The fixed-64 variant is experimental and is not integrated into the accepted branch.
  • The 132 direct checks comprise 126 F16/Q8_0 target cases and six Q4_K controls using 32 columns in both settings.
  • The source was committed after measuring; tested source hashes match the checkpoint, but the binary was not rebuilt from that clean checkpoint.
