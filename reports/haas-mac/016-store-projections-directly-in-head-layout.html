The nine-clip Q4_K screen reduced paired median request latency by 2.786%. On 30 clips the reduction was 0.316% with 17 faster inputs, while p90 rose from 129.65 to 130.44 ms and p99 from 150.98 to 151.18 ms. All 650 Q4_K transcriptions and their public token and segment fields matched. The full request benefit was too small to adopt the prototype.

Conditions and limitations

Time from before sending the first PCM16 chunk through receipt of the terminal result. File reading, model loading and warmup are excluded. Each measured input is warmed once per fresh worker.

Median over rounds for each input, then linearly interpolated p50, p90 and p99 across the measured input medians. RTFx divides total audio duration by summed request time.

Literal CER: Total Unicode code-point Levenshtein edits divided by total reference code points, including punctuation, symbols and whitespace.

Repository CER: NFKC followed by removing Unicode punctuation, symbols, separators and whitespace; no case folding or alternate-spelling substitutions. Edits and reference lengths are summed before division.

  • The current corpus is FLEURS Japanese test, with inputs from 6.36 to 28.2 seconds.
  • The p99 of a small duration-stratified sample is not a precise estimate of production tail latency.
  • The repository CER is not the published metric accepting alternative spellings of words.
  • Fresh-process load and first-request times do not reset filesystem or system Metal caches.
  • The primary table contains the full Q4_K result. The separate screen used the same nine inputs for its timing and quality passes. Only Q4_K advanced to 30 timed inputs and 650 quality inputs.
  • Ordinary original and candidate helper executables linked their respective retained product libraries. Those product builds matched on 74 compiler flag files and 74 link commands after paths were normalized. The fixed anchor used implicit architecture and SDK defaults, while the products selected arm64 and the SDK explicitly. Effective equivalence of those defaults was unverified. The primary OFF and ON comparison uses one candidate executable.
  • This M2 SIMD-group path stores F32 attention intermediates from MUL_MAT, PERMUTE and CONT in the final head layout for T ≥ 64. Q4_K, Q8_0 and F16 describe model weights. Other Metal generations and Vulkan were untested.
  • The ordinary-graph comparison observes complete projected bytes. The official F32 evidence covers features through encoded output. The request harness exposes text, public token metadata and segments. Raw TDT token IDs, frame positions and duration decisions were unobserved.
