Candidate

The ordinary (non-tensor) simdgroup kernel_mul_mm gains a MUL_MAT+UNARY+MUL epilogue on its STORE: the gate projection W_gate*x is sigmoid-ed as F32 and multiplied by the factor a inside the gate mat-mul's store.

  • The epilogue elides the materialization of the gate-MM intermediate and the sigmoid intermediate, and elides the two standalone elementwise dispatches (SIGMOID and MUL). The final MUL output is still materialized, written by the fused store.
  • The separate factor projection a = Wa*x and its materialization remain: not a two-projection or concatenated-weight kernel; more than 011a's standalone sigmoid/MUL fusion.
  • Speech source site: Encoder::convolution builds mul(pw1_a(h), sigmoid(pw1_gate(h))) — factor projection first, then the consecutive gate MUL_MAT, SIGMOID and MUL nodes the pattern matches (the twoproj fixture asserts this node order).
  • Kernel source: the non-tensor simdgroup branch of ggml/src/ggml-metal/kernels/mul_mm.metal (FC_mul_mm_glu / FC_mul_mm_glu_swap, an extra factor argument). Pattern and gate: ggml/src/ggml-metal/ggml-metal-fusion.cpp (GGML_METAL_FUSION_MUL_MAT_GLU).
  • The epilogue is not implemented on the tensor API/M5 path: the Metal kernel's tensor branch is untouched and the pattern is skipped on devices reporting the tensor API. M5 and Vulkan are untested by this trial.
  • No packing, dtype conversion, bias, new GEMM shape or altered multiplication loop; both MUL operand orders remain supported.

Safety contract — implemented and source-reviewed, unexecuted

Generic public-output, view and extra-consumer protections are retained: the pattern is a regular elision chain, so the generic chain, subgraph elidable-use and memory-range checks still apply. All activations (x, factor, gate MM, sigmoid, MUL) must share one Metal buffer, while weights may be separate.

  • FULL matching rejects final-output overlap with W or x, and MM/sigmoid overlap with the factor.
  • It rejects either elided MM/sigmoid output overlapping either W or x: the ordinary sequence has already overwritten those bytes by the time a later consumer runs, while the fused execution would skip the intermediate stores.
  • Only the exact final-in-place factor is permitted; partial overlap is rejected.
  • Both Metal-buffer intervals and underlying host addresses are checked, so multiple wrappers over one host arena cannot hide an alias.
  • The pattern is skipped in the allocation-dependency pass: zero new allocation dependencies and no extended input lifetimes; unsafe aliases are rejected at full matching after allocation.

Arithmetic and real limits

  • Full tiles retain the original K loop, operand staging, accumulators, workgroup geometry and stores; the factor tile is loaded at the same simdgroup tile origin and leading dimension, pairing each thread element with the matching gate accumulator element.
  • Tail tiles keep the existing scratch and barriers and apply the epilogue only to valid float4/scalar stores; the factor rows of a partial tile stay inside the valid tail.
  • Sigmoid is the ordinary 1/(1+exp(-gate)) evaluated with an intended F32 intermediate before a separately evaluated product; the multiply uses safe math and contract-off semantics in the fused MUL's original operand order. The full-tile path evaluates the sigmoid per scalar, while the existing standalone unary path operates on float4 values.
  • Compiler math and rounding therefore require an actual hardware bit comparison of the full-tile scalar sigmoid against the standalone float4 unary result; source equivalence is not evidence of exact bits, and no such comparison has been run.
  • Staging on this pinned backend: with default source precision, this ordinary large-MM path stages operands in half, including F32-weight × F32-activation storage; an explicit F32 src[1] hint selects F32 operand staging only for the F32-weight × F32-activation kernel. The gate's UNDEFINED src[1] requirement is a conservative eligibility check applied to all four weight types, separate from this staging selection; no precision threshold is relaxed.
